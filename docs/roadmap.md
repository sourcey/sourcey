# Roadmap

## Shipped

Sourcey already ships MCP reference, Doxygen support, godoc and rustdoc adapters, built-in markdown components, changelog feeds, llms.txt generation, light and dark appearances, search in the browser, four themes, and reproducible Docker and Nix packaging.

Version 3.7.1 adds readable Markdown for pages, operations and schemas, public OpenAPI bundles, configurable ARD and API discovery, and a separate docs MCP server. See [documentation for agents](machine-readable.md) for configuration and deployment.

Version 3.8.0 adds documentation [versions](versions.md) and [languages](languages.md), a [Try it](try-it.md) console on every API operation, site pages outside the documentation, and one-time [migrations](migrating.md) from Astro, Docusaurus, Mintlify and MkDocs.

Version 3.9 adds the site's own [components](components.md#your-own-components), page feedback, last-updated dates, breadcrumbs, release and star counts on a GitHub link, broken link checks, footnotes, Mermaid diagrams and git graphs drawn at build time, and references that split into pages as they grow.

## Planned

The next major product work is focused on documentation experience and ecosystem reach:

- incremental builds
- a VS Code extension and publishable theme packages

For the full running detail, keep `ROADMAP.md` as the source of truth in the repo root.
